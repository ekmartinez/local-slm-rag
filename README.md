# local-slm-rag
A local Retrieval-Augmented Generation (RAG) pipeline built on small language models, running entirely on a Raspberry Pi 5.

# Data

`deepspeed_fastgen_paper.pdf` is the paper *DeepSpeed-FastGen: High-throughput
Text Generation for LLMs via MII and DeepSpeed-Inference* by Connor Holmes and
10 other authors (Microsoft DeepSpeed), arXiv:2401.08671, January 2024.

Source: https://arxiv.org/abs/2401.08671
License: Creative Commons Attribution 4.0 (CC BY 4.0),
https://creativecommons.org/licenses/by/4.0/

The file is included unmodified for use as the example document in the
notebook.
